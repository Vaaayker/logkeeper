# Модуль Compression: канонічний Гаффман

**Відповідальний:** Міша
**Рівень складності:** базовий

| Питання Зрізу 0 | Відповідь |
|---|---|
| Що на вході | `byte[]` (серіалізовані записи журналу) |
| Що на виході | `byte[]`: довжини кодів + стиснуті біти (або режим NO_COMPRESSION) |
| Від кого дані | `Integration` (Pipeline) |
| Кому передає | `Security` (шифрування) |
| Перший тест | `CodeLengths("aabc")`; порожній вхід; один символ (довжина коду 1) |

Файли: `Huffman.cs`, `CompressionStats.cs`.

## Результати

Експериментальні виміри ефективності стиснення на базі `CompressionStats.Measure`:

| Тип вхідних даних | Оригінальний розмір (байти) | Стиснутий розмір (байти) | Коефіцієнт стиснення (Ratio) | Стиснення (%) | Примітка |
|---|---|---|---|---|---|
| Випадкові байти | 1000 | 1001 | 1.0010 | 0.0% | спрацював no compression, розмір не більше оригінал + 1 байт |
| 100 однакових записів | 1600 | 563 | 0.3519 | 64.8% | висока повторюваність, ratio менше 1 |
| 1000 згенерованих записів | 16000 | 9898 | 0.6186 | 38.1% | реальні логи через SerializeMany |
