# Модуль Security: захист, генетичний алгоритм, атака

**Відповідальний:** Таран Даня
**Рівень складності:** (обрати на Зрізі 0: базовий / просунутий / експертний)

| Питання Зрізу 0 | Відповідь |
|---|---|
| Що на вході | стиснуті `byte[]` + пароль; для ГА — параметри системи й функція якості Q |
| Що на виході | шифроване навантаження + HMAC; найкращі параметри від ГА; результат атаки |
| Від кого дані | `Compression` (стиснуті дані), `Integration` (для ГА — запуск Pipeline) |
| Кому передає | `Integration` (формує репліку LOG3) |
| Перший тест | `DeriveKeys` повертає два ключі по 32 байти |

Порядок операцій: стиснути → зашифрувати → додати HMAC (Encrypt-then-MAC).
.NET уже містить `Rfc2898DeriveBytes`, `Aes`, `HMACSHA256`; чи можна їх використовувати,
перевірити за методичкою й записати в `docs/decisions.md`.
Файли: `KeyDerivation.cs`, `AesCtr.cs`, `Mac.cs`, `GeneticAlgorithm.cs`, `WeakCipherAttack.cs`.
