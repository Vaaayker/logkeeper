# Модуль Classifier: багатошаровий перцептрон

**Відповідальний:** Проскура Даня
**Рівень складності:** (обрати на Зрізі 0: базовий / просунутий / експертний)

| Питання Зрізу 0 | Відповідь |
|---|---|
| Що на вході | вікно історії записів (з `team_config.json` — які часові ознаки обов'язкові) |
| Що на виході | клас запису: 0 — штатна, 1 — аномальна, 2 — перехід до інциденту |
| Від кого дані | `Core` (записи), `train.csv` / `valid.csv` |
| Кому передає | `Scheduler` (клас визначає цінність події) |
| Перший тест | завантажити `train.csv` і порахувати записи кожного класу |

Перцептрон пишемо самі (прямий прохід, backprop, SGD/Adam), готові NN-бібліотеки не використовуємо.
Файли: `DatasetLoader.cs`, `FeatureBuilder.cs`, `Mlp.cs`.
