# Модуль Scheduler: вибір копій (ДП) і порядок реплікації (жадібний)

**Відповідальний:** Ігор
**Рівень складності:** (обрати на Зрізі 0: базовий / просунутий / експертний)

| Питання Зрізу 0 | Відповідь |
|---|---|
| Що на вході | події з класом, `critical`, вагою `w_i` (біти); бюджет `W`; вузли з надійністю |
| Що на виході | кількість копій `r_i ∈ {0,1,2,3}` для кожної події; batch на кожен вузол |
| Від кого дані | `Classifier` (клас події), `Integration` |
| Кому передає | `Integration` (запис на вузли через `replication.py`) |
| Перший тест | рюкзак 0/1 на маленькому прикладі з відомою відповіддю |

Файли: `Knapsack.cs` (ДП), `GreedyScheduler.cs` (жадібний baseline), `Placement.cs` (вузли і batch).
