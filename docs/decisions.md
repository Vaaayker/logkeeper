# Лог рішень

Формат запису: **проблема → варіанти → рішення → чому**.
Потрібно щонайменше 5 записів до кінця проєкту. Новий запис додає той, хто прийняв рішення.

## D-001. Мова реалізації
- **Проблема:** обрати мову програмування для всього проєкту.
- **Варіанти:** (1) Python; (2) інша мова.
- **Рішення:** Python.
- **Чому:** модель вузлів видається готовим файлом `replication.py` на Python; для тестів використовуємо `pytest`; усі в команді знають Python.

## D-002. Структура репозиторію
- **Проблема:** як розділити код між п'ятьма людьми, щоб не заважати одне одному.
- **Варіанти:** (1) один спільний каталог; (2) один модуль (пакет) на людину.
- **Рішення:** один модуль на людину: `integration`, `compression`, `scheduler`, `classifier`, `security`.
- **Чому:** менше конфліктів при merge, зрозуміло, хто за що відповідає, кожен модуль тестується окремо.
