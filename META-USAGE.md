# META-USAGE

Прозорий опис використання систем штучного інтелекту (ШІ) у проєкті.
Записуємо суттєве використання одразу, а не наприкінці семестру.

## Використані інструменти

- Claude Code (Anthropic) — асистент у редакторі VS Code.

## Для чого використовувалися

### Приклад 1. Завершення інтеграційного конвеєра (issue «повний наскрізний запуск»)
**Задача:** реалізувати багатоваріантний рюкзак `Knapsack.ChooseCopies`, `ReplicationBridge.RunPython`,
`Pipeline.Run`, генетичний алгоритм і атаку на слабкий шифр, App, проєкт експериментів, документацію.
**Що було використано:** чернетки коду й тестів для перелічених класів, опис рішень D-005…D-008,
структура експериментів і таблиць у `results/`.
**Що зроблено студентом:** постановка задачі й обмежень (issue), перевірка формул (ДП, u_i(r) = v_i·(1 − p^r),
визначення S/R/T/Q), запуск `dotnet test` і всіх експериментів, перегляд результатів і рев'ю PR.
Код решти модулів (Гаффман, перцептрон, PBKDF2/AES/HMAC, LOG3, жадібний планувальник)
написано командою раніше без цього інструмента — його лише викликає Pipeline.

## Що не передавалося ШІ

- приховані дані;
- паролі та секретні ключі;
- закриті матеріали викладача.

## Відповідальність

Команда перевірила весь код, формули, тести і результати та несе відповідальність за їх правильність.
