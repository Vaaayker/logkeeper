# Модуль integration — інтеграція та відновлення

**Відповідальний:** Максим
**Рівень складності:** (обрати на Зрізі 0: базовий / просунутий / експертний)

| Питання Зрізу 0 | Відповідь |
|---|---|
| Що на вході | потік записів журналу; репліки (`bytes`) після відмов; пароль |
| Що на виході | відновлений журнал без дублікатів; частка відновлених критичних подій; метрика Q |
| Від кого дані | `classifier` (клас), `scheduler` (план копій), `compression`, `security` |
| Кому передає | викладачу/звіту (результат), `security` (параметри для ГА) |
| Перший тест | `Record` → `serialize` → `parse` → той самий `Record` |

Файли: `record.py` (16-байтовий запис), `packet.py` (формат репліки LOG3),
`recovery.py` (відновлення і дедуплікація), `pipeline.py` (весь шлях даних),
`metrics.py` (S, R, T, Q).
