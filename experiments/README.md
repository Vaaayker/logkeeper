# Експерименти

Код для таблиць і графіків звіту. Окремий консольний проєкт `LogKeeper.Experiments`
з'явиться пізніше; кожен експеримент буде окремою командою
(`dotnet run --project experiments/LogKeeper.Experiments -- <назва>`),
результати пишуться в `results/`.

Плановані експерименти:

- `dp-vs-greedy` — ДП проти жадібного алгоритму
- `classifier` — macro-F1 і матриця помилок перцептрона
- `ga` — збіжність ГА проти випадкового пошуку
- `ablation` — вплив блоків (без перцептрона / ДП / ГА)
- `final` — фінальні метрики S, R, T, Q
