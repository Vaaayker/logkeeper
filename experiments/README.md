# Експерименти

Скрипти для таблиць і графіків звіту. Кожен скрипт запускається окремо
(`python experiments/run_<назва>.py`), результати пишуться в `results/`.

Плановані скрипти (з'являться пізніше):

- `run_dp_vs_greedy.py` — ДП проти жадібного алгоритму
- `run_classifier.py` — macro-F1 і матриця помилок перцептрона
- `run_ga.py` — збіжність ГА проти випадкового пошуку
- `run_ablation.py` — вплив блоків (без перцептрона / ДП / ГА)
- `run_final.py` — фінальні метрики S, R, T, Q
