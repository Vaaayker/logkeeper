# Модуль Core: спільні типи

**Відповідальний:** Максим

Тут лежить те, що потрібно кількома модулям одночасно (щоб не було циклічних залежностей):
`LogRecord` і `RecordCodec` (16-байтовий запис). Некоректні дані скрізь позначаємо
стандартним `FormatException`.

Перший тест: `Parse(Serialize(r)) == r`.
